# PronFlow · 专治口语失语

心里有中文，开口就是英文。PronFlow 是一款**场景化口语训练 Web APP**（手机优先），不做传统背单词，一切功能只为解决：开口卡顿、想说不会说、临场失语。

## 快速开始

```bash
npm install       # 安装依赖
npm run dev       # 启动开发服务器 http://localhost:5180
npm run build     # 生产构建（输出 dist/）
npm run dict      # 重新生成开源大词库 public/dict/dict.json
```

> 推荐用 Chrome / Edge 打开以获得最自然的英语语音（系统 Natural 人声）。手机上可用浏览器「添加到主屏幕」当 APP 用。

## 核心功能

- **20 个内置生活场景**：地铁公交 / 打车 / 机场 / 酒店 / 居家 / 校园 / 社交 / 点餐 / 购物 / 就医 / 情绪 / 求助 / 拒绝 / 赞美 / 职场 / 快递外卖 / 电话 / 天气 / 健身 / 租房，共 600+ 条口语原生素材
- **统一素材标准**：每条都含 美式+英式双音标、通俗口语化翻译、1–3 条对话例句、简单/日常/地道多版本替换、口语使用度标注（高频口语/口语可用/书面慎用）；句子另含长句拆分（零基础逐段开口）与连读/弱读/吞音标注
- **口语训练三模式**：中文遮屏自测（只显中文→开口→对照→评分，卡住自动进次日复习）、慢速跟读（0.55× 慢速 + 连读标注切换 + 逐段播放 + **录音回放对照**）、句式仿写（槽位点选实时造句并可播放）
- **中文搜英文**：全局搜索输入心里想说的中文，直接推送地道英文（中英互搜、模糊/精准、搜索历史、结果分组）
- **独立大词库**：18,746 词条（ECDICT 开源数据 + CMU 美音词典合成双音标），按 四级/六级/考研/雅思/托福/高考/中考/高频词 筛选；322 个高频口语词叠加完整口语字段（对话例句/同义替换/口语度）
- **收藏 + 每日复习**：收藏即入复习体系，间隔重复（说出去间隔翻倍、卡住明天再来），每日清单上限 20 条
- **自定义体系**：自定义场景新建/重命名/编辑/删除/置顶，**中文名自动联想英文名、图标可上传图片**；自定义单词/短语/句子支持**词库模糊联想一键带出词性/音标/释义/例句**，同步进全局搜索与复习
- **PWA 离线**：添加到主屏幕即像原生 APP 全屏运行，应用壳 + 词库本地缓存，**断网也能学**（云端发音除外）
- **数据自主**：全部存本机 localStorage，支持 JSON 导出/导入备份；无广告无弹窗

## 发音说明

使用系统语音合成引擎（Web Speech API），内置美音 en-US / 英音 en-GB 双口音，支持单点 / 循环 / 慢速播放，自动优先选择系统中最自然的语音（如 Microsoft Natural / Google 语音）。若「我的」页显示 0 个英语人声，请改用 Chrome / Edge 或在系统中安装英语语音包。

## 目录结构

```
src/
├── data/            # 20 个场景素材 + 词库回退数据 + 口语增强层
│   └── scenes/      # 每场景一个文件（词/短语/句）
├── services/        # TTS 发音、全局搜索、词库加载、复习调度
├── store/           # 用户数据层（localStorage）
├── components/      # 素材卡片、发音按钮、词库行、表单等
└── pages/           # 场景/词库/搜索/复习/训练/我的
scripts/build-dict.mjs   # ECDICT+CMU → public/dict/dict.json 预处理
public/dict/dict.json    # 生成的开源大词库（随仓库分发）
```

## 数据来源与许可

- 场景素材为原创口语内容
- 大词库基于 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License）与 [CMUdict](https://github.com/cmusphinx/cmudict)（BSD 类许可）预处理生成，仅用于学习用途
